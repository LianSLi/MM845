# Reinforcement learning for simplifying 3-manifold triangulations (Pachner moves)

A single Fitted-Q agent (scikit-learn MLP) learns to choose among the **2-3, 3-2 and 4-4 Pachner moves** to shrink
one-vertex triangulations of **Dehn fillings** of cusped census manifolds (SnapPy / `t3mlite`). The agent is compared with
greedy heuristics and a biased random walk, using *paired* trials (every method starts from the identical scrambled
triangulation), and stress-tested on scrambles of exactly 100 tetrahedra.

The write-up is `report/main.pdf`; every number and figure in it is generated by the scripts below.

## 1. Set up the environment

Python 3.10 or newer (developed and tested with 3.13). Linux or macOS; no GPU needed. Choose **A (conda)** or **B (venv)**; both install the same pinned versions.

**A. conda** (uses `environment.yml`):

```bash
git clone <this repository> pachner-rl && cd pachner-rl
conda env create -f environment.yml    # creates the environment "pachner-rl" (Python 3.13)
conda activate pachner-rl
python scripts/check_setup.py          # ~10 s, prints "OK" if everything works
```

**B. venv**:

```bash
git clone <this repository> pachner-rl && cd pachner-rl
python3 -m venv .venv
source .venv/bin/activate              # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt        # pinned: snappy 3.3.2, numpy 2.4.4, scikit-learn 1.8.0, matplotlib, scipy
python scripts/check_setup.py          # ~10 s, prints "OK" if everything works
```

* `environment.yml` (conda) and `requirements.txt` (venv) pin the same versions. `requirements-lock.txt` is the full `pip freeze` of the tested environment.
* `requirements-notebooks.txt` additionally installs Jupyter, only needed for `notebooks/`.
* The trained agent in `checkpoints/ver2_checkpoint.pkl` is a pickled scikit-learn model; load it with the pinned
  scikit-learn version (pickles are not guaranteed to load across versions). The root file `pachner_agent.py` is a
  compatibility alias required by that pickle.
* Set `OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1` for speed (the MLPs are tiny); `scripts/reproduce.sh` does this.

## 2. Reproduce the central results

```bash
bash scripts/reproduce.sh quick        # ~1 minute: 3 seeds of the paired test + 5 zero-shot 100-tet scrambles -> results/quick/
bash scripts/reproduce.sh full         # ~30 minutes on one core: everything in the report, rebuilds report/main.pdf (needs pdflatex)
```

`full` runs, in order (each step can also be run alone; all are resumable or deterministic given the stored start
triangulations):

| step | command | output |
|---|---|---|
| (optional) instances | `python scripts/make_instances.py` | `configs/instances.json` (shipped; regenerating draws new random SnapPy triangulations) |
| paired test, real fillings | `python scripts/evaluate_paired.py real --seeds 50` | `results/paired_real.jsonl` |
| paired test, synthetic | `python scripts/evaluate_paired.py synth --seeds 50` | `results/paired_synth.jsonl` |
| statistics | `python scripts/summarize_paired.py` | `results/paired_summary.json` (success rates, bootstrap CIs, sign tests) |
| training statistics | `python scripts/training_stats.py` | `results/training_stats.json` |
| 100 tets, zero-shot | `python scripts/large_scale.py zeroshot` | `results/large_zeroshot_4_1(5,1).json` |
| 100 tets, fine-tune | `python scripts/large_scale.py finetune --episodes 200` (the shipped `checkpoints/large100_checkpoint.pkl` is reused; delete it to retrain, ~15 min) | `checkpoints/large100_checkpoint.pkl`, `results/large_finetune_log.json` |
| 100 tets, competition | `python scripts/large_scale.py compete` | `results/large_compete.json` |
| figures and LaTeX tables | `python scripts/make_figures.py && python scripts/make_tables.py` | `report/figs/*.pdf`, `report/numbers.tex`, `report/tab_*.tex` |
| report | `cd report && pdflatex main && pdflatex main` | `report/main.pdf` |

Retraining the main agent from scratch (900 episodes, resumable; `--time-limit` stops after that many seconds):

```bash
python scripts/train_agent.py --checkpoint checkpoints/my_agent.pkl
python scripts/evaluate_paired.py real --checkpoint checkpoints/my_agent.pkl --out results/my_real.jsonl
```

### Notes on reproducibility

* **SnapPy is randomized.** `filled_triangulation()`, `randomize()` and `simplify()` return different (equivalent)
  triangulations on every call. To make evaluations repeatable, the start triangulations are drawn once and stored by
  isomorphism signature in `configs/instances.json`, and are rebuilt with
  `snappy.Triangulation(sig, remove_finite_vertices=False)` (the flag matters: by default SnapPy replaces the closed
  one-vertex triangulation with a small cusped one). The "best-known" sizes are minima over 200 randomized
  simplification restarts; they are upper bounds on the true minimum, not proofs of minimality.
* With the shipped instances and checkpoint, `evaluate_paired.py` is deterministic (all random choices are seeded). A fresh
  `make_instances.py` or a fresh training run will change numbers slightly; training is not bit-reproducible because the
  training instances are drawn with SnapPy's own randomness.
* Expect `reproduce.sh quick` to reproduce the *direction* of the results (RL above the naive greedy baselines, RL close to the balanced greedy
  baseline, no RL advantage at 100 tetrahedra); the confidence intervals are wide with 3 seeds.

## 4. Method in brief

* **State** (6 features): `n/n0`, steps left, fractions of edges with valence <=3, =4, >=6, edges/`n0`.
* **Action** (6 features): move-type one-hot, change in tetrahedra / 3, mean and max valence of the edges involved.
* **Reward**: tetrahedra removed minus 0.02 per move; -1 for a failed move; +5 and episode end when the target size is reached.
  The agent is not told the target or whether an instance is real or synthetic.
* **Learner**: MLP (64, 64), Adam, Fitted-Q with gamma 0.97, epsilon-greedy with type-balanced random moves.
* **Training**: 900 episodes, one shared agent; synthetic scrambles of minimal census manifolds (70% -> 30%) mixed with real Dehn fillings
  (11 training instances from 6 source manifolds).
* **Evaluation**: paired trials on 5 held-out fillings and on synthetic scrambles; success = reaching the best-known (real) or known minimal (synthetic) size.
